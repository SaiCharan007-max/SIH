# Frontend Dashboard

This directory is reserved for the upcoming web client dashboard (React) for **SIH26027**: *"AI-Powered Automatic Block Planning to Maximize Asset Availability for Train Operations on Indian Railways"*.

## Future Scope
- **Interactive Section & Yard Views**: Visualization of railway sections, track layouts, and corridor topology.
- **Block Planning & Gantt Charts**: Interactive schedule visualization displaying train timetables alongside proposed maintenance block windows.
- **What-If Analysis & Approvals**: UI for section controllers, chief controllers, and departmental engineers (Engineering, Traction Distribution, S&T) to review, validate, and approve scheduled blocks.

*Note: As per our incremental implementation roadmap, this module will be implemented in future phases.*
